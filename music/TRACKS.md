# Act Two arena tracks (9 new levels)

Arena music is filename-driven: drop each finished track in `/music/` named
**exactly** after its level (apostrophes stripped, `.mp3`) and it plays
automatically — no code change. None of the Act Two names contain apostrophes,
so the filenames below are literal.

Each entry is a comma-separated style prompt for generating the track.
